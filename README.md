# React + TypeScript Components Exercise

A simple TypeScript checkpoint demonstrating conversion of React components from JavaScript to TypeScript.

## Description

This project converts two React components to TypeScript:
- **Greeting** — A functional component with typed props
- **Counter** — A class component with typed state and methods
